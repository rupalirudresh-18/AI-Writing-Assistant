# AI Writing Assistant

An AI-powered writing application built with Python, Streamlit, and Google's Gemini API.

## Features

- Blog post generation
- Professional email drafting
- Code explanation in simple language
- Social media post generation
- Adjustable creativity using temperature controls
- Writing tone and word-count settings
- Markdown-formatted output
- Download generated content as a Markdown file

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI Python SDK
- python-dotenv

## Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Create a `.env` file and add `GEMINI_API_KEY=your_api_key`.
5. Run `streamlit run app.py`.

## Security

Never commit API keys or `.env` files to version control.
